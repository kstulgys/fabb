## Findings considered and rejected

So nobody re-audits these:

- **Destructive deletes have no confirmation** (prior `.impeccable` critique P1):
  **already fixed** in the working tree — `src/app/confirm-delete-button.tsx`
  exists and is used by both `auto-book-rules.tsx` and `training-log.tsx`.
- **Intensity hearts rendered two ways** (prior P2): **already fixed** — a single
  `src/app/dashboard/intensity.tsx` (Lucide `LuHeart`) is used everywhere; no
  more `"❤".repeat()` emoji.
- **Spinners where skeletons belong** (prior heuristic): **already fixed** —
  `src/app/dashboard/skeletons.tsx` provides content-shaped skeletons for
  Schedule, lists, and Stats.
- **Run-log outcome only in a hover `title`** (prior Sam/a11y flag): **already
  fixed** — `auto-book-rules.tsx` now uses `aria-label` on the run badges.
- **Charts have no text alternative** (prior Sam/a11y flag): **already fixed** —
  `stats.tsx` renders an `SrChartTable` (screen-reader table) per chart.
- **Stats tab is neutral/template-shaped** (prior P2): **already addressed** — the
  teal `Scoreboard` hero now provides the sanctioned teal-forward moment.
- **"Missed" vs "Didn't go" naming** (prior minor): no longer reproducible — the
  badge and toggle both use "Didn't go"/"Attended" consistently.
- **Stats empty-state could mis-fire for an empty period**: **not a bug** —
  `convex/stats.ts:71,80` gates the empty state on all-time `topTypes`, so a
  period with zero classes still shows the scoreboard/charts, not the empty state.
  (The *partial period scope* that remains is real and is plan 007.)

### Deferred / minor (real but not planned; raise if you want them)

- No "last updated" freshness cue for the hourly schedule cache (trust signal).
- Heading semantic levels: visual `size` is decoupled from `<h*>` level; likely
  no `<h1>` on the dashboard (document-outline a11y).
- Live-availability count goes stale after a successful "Book now" (it isn't
  refetched before the user closes the sheet).
- Settings/onboarding `PoolDetailsForm` briefly flashes empty fields before the
  prefill effect runs.
- Bulk/accelerator paths for power users (multi-rule add, keyboard shortcuts) —
  acceptable to omit at this app's scale.
